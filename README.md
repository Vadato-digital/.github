# .github

Dépôt spécial de l'organisation vadato-io. GitHub y lit :

- `profile/README.md` : la page d'accueil de l'organisation ;
- `PULL_REQUEST_TEMPLATE.md`, `CONTRIBUTING.md`, `SECURITY.md` : les fichiers par défaut des dépôts qui n'ont pas les leurs ;
- `workflow-templates/` : le modèle de CI proposé dans l'onglet Actions des dépôts.

Ce dépôt doit rester public pour que GitHub applique ces fichiers par défaut. Il ne contient
donc rien de confidentiel. Les scripts d'administration et le handbook sont dans le dépôt privé
`engineering`.
