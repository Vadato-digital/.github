# Sécurité

Pour signaler une vulnérabilité ou un secret exposé dans un dépôt Vadato : écrivez à
hello@vadato.io avec le nom du dépôt, le fichier ou le commit concerné, et la façon de reproduire.
Merci de ne pas ouvrir d'issue publique pour ce type de signalement.

Un secret exposé est considéré comme compromis : il est renouvelé chez le fournisseur avant toute
autre action.
